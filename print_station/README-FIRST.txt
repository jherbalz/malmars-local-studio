MALMARS LOCAL PRINT STATION — CURRENT FREE BETA
==========================================

This file replaces an obsolete demo handout. That older copy described
automatic slicer driving and model-to-printer sending; those are not part of
the current beta.

Use `build\free-beta-1.5.2\` or run `START_PRINT_STATION.cmd` from this source
folder. The app opens the selected model in a visible external slicer for you
to inspect and adjust. It does not send or start a model print. Bed priming
and printer controls are separate, explicit actions.

There is no account, cloud service, telemetry or internet upload. Model and
source-photo handoffs between local apps remain on this PC; printer traffic
uses your local network. Do not share the app's writable data folder.

The free-beta terms and third-party notices are shipped with the clean
package. Flashforge Studio and other slicers are separate products and are
not bundled.
